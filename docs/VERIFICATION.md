## v0.2.0 初始版本

## 本地验证

- Windows、Python 3.11.11；独立虚拟环境，不继承系统 site-packages。
- PyMuPDF 2.1、OpenCC 1.4.2、Pillow 13.0.0，使用项目既有 Pandoc 可执行文件。
- 82 项单元/集成测试通过。没有依赖私人书籍配置或真实 Paddle 模型元数据。
- 原创两页夹具通过六个阶段；首轮模拟视觉纠错保留一个演示错字，独立视觉复核导入后，再由模拟文本补漏和独立判断修复。最终 EPUB 包检查通过，正文确实包含第二轮修补。
- 部分页样本经过全部阶段后仍标记为部分书籍；不会在中途扩展成未经审查的全书。
- 从 wheel 安装后，在源码目录外执行完整演示成功；确认环境没有 Paddle 或 Torch。此验证使用模拟模型响应，不代表真实 AI 或 GPU 推理的质量测试。
- wheel 和 source distribution 均可构建；出版文件、API 回答及运行环境不在公开源码或分发包内。
- 暂存文件经过路径、文件体积和凭据检测；额外在内存中比对本机真实 API 密钥，未发现其进入待发布文件。扫描不等于对未知形式秘密的绝对保证。

## 持续集成

GitHub Actions 配置测试 Windows/Linux 与 Python 3.11/3.12，并执行单元测试、原创演示、发布边界扫描、wheel/sdist 构建以及 Linux 下从 wheel 的独立运行。实际远端结果以仓库 Actions 页面为准，本地验证不冒充远端矩阵全部通过。

## 验证范围

测试证明本项目的流程衔接、来源检查、断点复用、勘正应用边界和出版结构可以运行。它不证明任意 PDF 的阅读顺序都正确、任意模型意见都准确，也不证明第二模型一定更强。真实 OCR 的 CUDA/驱动兼容性及具体模型的识别质量需要在目标机器和书籍上分别测试。
